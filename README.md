# adyetubar modif

UDP server installation for ZIVPN Tunnel (SSH/DNS/UDP) VPN app.
<br>

>Server binary for Linux amd64 and arm.

#### Installation AMD
```bash
wget -O lom.sh [https://raw.githubusercontent.com/jalom88/adyetubar/main/lom.sh](https://raw.githubusercontent.com/jalom88/adyetubar/main/lom.sh); sudo chmod +x lom.sh; sudo ./lom.sh

bash <(curl -fsSL [https://raw.githubusercontent.com/jalom88/adyetubar/main/lom2.sh](https://raw.githubusercontent.com/jalom88/adyetubar/main/lom2.sh))

sudo wget -O ziun.sh [https://raw.githubusercontent.com/jalom88/adyetubar/main/uninstall.sh](https://raw.githubusercontent.com/jalom88/adyetubar/main/uninstall.sh); sudo chmod +x ziun.sh; sudo ./ziun.sh
